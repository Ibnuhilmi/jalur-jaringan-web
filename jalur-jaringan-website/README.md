# JalurJaringan - Landing Page Peta Karier IT & Teknologi Berbasis Web

Proyek Landing Page Web interaktif yang menyajikan peta karier di bidang jaringan komputer dan teknologi siber. Dikembangkan untuk memenuhi tugas mata kuliah Pengantar TI dan TIK (2026/2027) oleh Kelompok 5 Program Studi Teknik Multimedia dan Jaringan, Politeknik Negeri Jakarta.

## Fitur Utama

- Hero Section: Pengenalan prospek kerja jaringan IT berdasarkan laporan WEF Future of Jobs Report.
- Interactive Role Tabs (Profesi): Komponen tab interaktif (Network Engineer, Network Administrator, NOC Engineer, Network Security Engineer).
- Skill Matrix: Pembagian kompetensi teknis (Hard Skill) & non-teknis (Soft Skill).
- 5 Steps Roadmap: Panduan tahapan belajar berurutan bagi pemula & mahasiswa.
- Responsive & Clean UI: Desain modern berbasis CSS Variables & Mobile-First Flexbox/Grid.
- Cybersecurity & Web Security Standard: Implementasi Content Security Policy (CSP) Meta Tag, DOM sanitization, dan keyboard focus.
